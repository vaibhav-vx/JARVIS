## 🌐 Adopted Repository Skills Matrix

This project adopts and enforces specialized skill modules distilled from 14 world-class open-source repositories:

### 1. Loop Engineering Skill
* **URL**: `https://github.com/cobusgreyling/loop-engineering.git`
* **Skill Definition**: Closed-loop iterative execution (`Plan → Execute → Build Test → Reality Check → Verify`).
* **Rule**: Never end a turn without verifying build compilation (`npm run build`) and confirming zero terminal or runtime errors.

### 2. Chrome DevTools Diagnostics Skill
* **URL**: `https://github.com/ChromeDevTools/chrome-devtools-mcp.git`
* **Skill Definition**: Real-time browser DOM inspection, console error log extraction, network 404 elimination, and Core Web Vitals checks.
* **Rule**: Instantly diagnose and fix any console 404 missing resource or property error.

### 3. Agentic Executable Skills Framework
* **URL**: `https://github.com/agentskills/agentskills.git`
* **Skill Definition**: Modular, structured skill definition format using strict frontmatter instructions, parameters, and deterministic tool calls.

### 4. Caveman Direct Communication Skill
* **URL**: `https://github.com/JuliusBrussee/caveman.git`
* **Skill Definition**: High-density, direct technical communication. Eliminates filler fluff, artificial praise, and sycophantic greetings.

### 5. Superpowers Tool Orchestration Skill
* **URL**: `https://github.com/obra/superpowers.git`
* **Skill Definition**: Advanced tool usage strategies including daemon background commands, regex grep searches, file replacements, and scheduling.

### 6. Awesome Design System Skill (`DESIGN.md`)
* **URL**: `https://github.com/VoltAgent/awesome-design-md.git`
* **Skill Definition**: Enforces strict `DESIGN.md` guidelines:
  * **Color System**: HSL dark mode palette, Titanium Gunmetal gradients (`#181b22` to `#2b313e`), Obsidian cards (`#000000` to `#242428`).
  * **Typography**: Orbitron for HUD headers/titles, Rajdhani for badges, Inter for body copy, JetBrains Mono for codes/timestamps.
  * **Glassmorphism**: `backdrop-blur-xl`, `bg-black/60`, `border-gray-800`.
  * **Grid & Alignment**: Responsive CSS Grid (`grid-cols-1 md:grid-cols-2 lg:grid-cols-3`), 16:9 rectangular video player aspect ratios.

### 7. Front-End Checklist QA Audit Skill
* **URL**: `https://github.com/thedaviddias/Front-End-Checklist.git`
* **Skill Definition**: 385-point production quality audit:
  * **Accessibility**: ARIA labels, semantic HTML tags (`<header>`, `<main>`, `<footer>`, `<section>`), keyboard navigation, proper color contrast.
  * **Performance**: Code-splitting via Next.js App Router, static page prerendering, optimized media loading.
  * **SEO**: Page titles, meta descriptions, canonical URLs, semantic `<h1>`/`<h2>` heading hierarchy.
  * **Security**: Input validation (email format, 10-digit phone number), environment variable isolation (`.env.local`).

### 8. Multi-Agent Persona Orchestration Skill
* **URL**: `https://github.com/microsoft/ai-agents-for-beginners.git`
* **Skill Definition**: Role-based cognitive execution. Simulates the 13 specialized engineering team personas (Architecture, PM, Engineering, QA, Security, AI, Reality Audit, etc.) on every code review.

### 9. System Design & Architecture Skill
* **URL**: `https://github.com/donnemartin/system-design-primer.git`
* **Skill Definition**: High-availability software patterns, decoupled API client layers (`src/app/lib/supabase.ts`), type-safe state management, and error handling.

### 10. Public Data & API Hydration Skill
* **URL**: `https://github.com/public-apis/public-apis.git`
* **Skill Definition**: Seamless integration with external web APIs, Web Speech API (TTS/STT), Supabase PostgreSQL endpoints, and WebAR targets.

### 11. Deep Code Inspection & Zero-Guessing Skill
* **URL**: `https://github.com/Egonex-AI/Understand-Anything.git`
* **Skill Definition**: Never guess file paths, variable names, or component prop keys. Always inspect authoritative code with `view_file` or `grep_search` before editing.

### 12. Agentic Awesome Skills Catalog
* **URL**: `https://github.com/sickn33/agentic-awesome-skills.git`
* **Skill Definition**: Reusable automation workflows for React/Next.js component generation, Tailwind utility conversion, and build verification.

### 13. Technical Best Practices & Curation Skill
* **URL**: `https://github.com/sindresorhus/awesome.git`
* **Skill Definition**: Adhering strictly to modern React 19, Next.js 16 App Router, TypeScript, and Lucide React standards.

### 14. Fundamental Component Building Skill
* **URL**: `https://github.com/codecrafters-io/build-your-own-x.git`
* **Skill Definition**: Dependency-lean software engineering. Custom AR scanner simulator, custom countdown timer, and native speech handlers built cleanly without bloated third-party plugins.
